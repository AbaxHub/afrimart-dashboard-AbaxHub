# AfriMart Sales Dashboard
Tool used: Power BI
Dataset: AfriMart_Sales_Dataset.xlsx (700 transactions, 10 countries, 7 products)
## Key findings
1. … Nigeria is doing well by generating highest revenue overall, while Senegal has low revenue generated overall, we should investigate what Nigeria is doing well so that we can, apply it to low performing countries, to improve their performance regarding revenue   
2. … We can see that Rice (50kg Bag) and Palm Oil (5L) generated more profits for us, so we should encourage cross-selling, as we know we need Palm Oil to cook our soup so that we can eat our rice. by ensuring cross-selling of both products, we will be able to generate more profits.
 3. …The revenues increase between 2024 to 2025, while we have it decreased between 2025 to 2026. drilling down through year 2025. it can be seen that there was low revenue generated November 2025, which was the source of the drop in revenue 2025 to 2026. So, the reason for the low sales in that period (November 2025) should be investigated, so that corrective measure can be taking. to prevent another future occurrence of such.
